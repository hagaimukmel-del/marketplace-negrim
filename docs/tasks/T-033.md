## Context
Every carpentry registers with a phone, and on a job site WhatsApp is nearer than email. The
email code (`lib/login-code.ts`) is built so the sender can change: issue the code, send it,
verify it the same way.

## Done when
A carpentry can choose to get the code on WhatsApp, sent through the WhatsApp Business
Platform (Meta Cloud API or a provider such as Twilio) with an approved "authentication"
template.

## Notes
Needs a WhatsApp Business account, a verified business in Meta Business Manager, a sending
number and per-message cost (authentication conversations are paid). Not started.
