## Context
Owner's request 2026-10-08: an internal mail ("סגנון פעמון") so carpenters and suppliers can talk
inside the site, including about orders. Today "שאלה לספק" (`supplier_contact_requests`) is one-way:
the supplier sees the last 20 questions and answers by phone or WhatsApp; nothing comes back into
the site and nothing is marked handled.

## Done when
- A bell with unread count for the carpenter (`/app`) and the supplier (`/supplier`).
- A thread per question and per order; the supplier replies in the site, the carpenter is emailed
  and sees the reply in the thread; a thread can be marked "טופל".
- Existing `supplier_contact_requests` rows open as threads.
- Admin sees that a thread exists and whether it was answered, not its content
  (admin visibility table in the plan doc, approved 2026-10-08).
- Email only for notifications; no WhatsApp/SMS (owner, 2026-10-08).
