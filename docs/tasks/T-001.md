## Context
Announced publicly as coming ("בהמשך הזמנה קולית בפחות מדקה"). The agent chat has a mic button (`ChatContainer.tsx`, browser Web Speech API, `he-IL`) shown only where the browser supports it. It fills the input and, since 2026-10-18, sends the message when the carpenter stops talking. It has not been tried on a phone; the same API on the removed legacy `/order` page didn't work on iOS Safari. Since 2026-10-18 a written quantity ("20 ק״ג") reaches the cart (`lib/agent-quantity.ts`).

## Done when
A carpenter speaks a request in the chat (phone, Hebrew) and gets from speech to a sent purchase order in under 60 seconds, measured on staging with the smoke-test skill. It works on iOS Safari and Android Chrome.
