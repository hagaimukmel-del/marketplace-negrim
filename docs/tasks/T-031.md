## Context
`lib/rate-limit.ts` counts in memory. On Vercel each instance keeps its own count and a cold start
resets it, so "10 questions per hour" for "שאלה לספק" (`api/carpenter/contact-supplier`), quote
requests, messages and `/api/join` are softer than they read.

## Done when
The limits that guard an email to a supplier (supplier question, quote request, message) count
from their own table rows in the window (e.g. `supplier_contact_requests.created_at`), with the
in-memory check kept as a fast first gate.
