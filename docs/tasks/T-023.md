## Context
Decided by the owner 2026-10-08 (plan doc "תוכנית: מפת הספקים והאדמין", section "מודל משולב"):
a combined model. Each supplier chooses "show prices" or "quote only". The owner's supplier
(איתמיר) keeps prices visible. Prices are never deleted; switching back is instant.

Today every live offer shows its price to a signed-in carpenter (`lib/app/catalog-server.ts`,
`lock_prices`). The closest thing to a quote request is "שאלה לספק" from the agent chat
(`supplier_contact_requests`, area 3), which carries text only and no price back.

## Done when
- A supplier setting (Terms tab) "להציג מחירים / רק הצעת מחיר".
- For a quote-only supplier, the server strips the price from catalogue, product page, search and
  agent results (not only hidden in the UI). Admin and other suppliers never see it either.
- The carpenter sees "בקש הצעת מחיר" instead of a price, can ask for a quantity, and the request
  sits apart from directly orderable lines in the cart.
- The supplier answers in the console (price, validity); the carpenter approves and it becomes a
  normal purchase order through `/api/orders` with the quoted price snapshotted.
- "בקש הצעה לכמות גדולה" is also offered on products that do show a price.
- The agent only prepares (add to cart / request a quote); the carpenter sends.
- Admin sees that a request exists and whether it was answered, not the quoted price.
