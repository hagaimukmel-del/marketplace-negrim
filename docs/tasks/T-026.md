## Context
Owner 2026-10-08: a supplier must state where it delivers. Today suppliers have no regions; a
carpenter in Eilat can order from a supplier that never reaches there. `lib/regions.ts` already
holds the seven regions and `regionsForCity()`, used by carpenter registration and the Metzion.

## Done when
- Delivery regions (and an optional delivery fee / free-delivery threshold) are a required field
  in the supplier's Terms tab and in supplier registration.
- Catalogue, product page, cart and agent prefer suppliers that deliver to the carpenter's region;
  a supplier that doesn't is marked "לא מגיע לאזור שלך" (or self-pickup only) and is not the
  default in `bestOffer()`.
