## Context
The supplier console (`src/app/supplier/tabs/OrdersTab.tsx`) can mark lines unavailable, set a
delivery date and reject with a reason (`/api/supplier/orders`, action `reject`). The signed
"confirm order" link in the supplier's email (`src/app/supplier/confirm/[token]/`,
`/api/supplier/confirm`) still only confirms the whole order with an optional amount and note.

## Done when
The confirm page offers the same three options, or links into the console for them.
