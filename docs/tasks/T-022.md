## Context
The owner (2026-10-07) wants the carpenter to get a file of an order, and a price quote before ordering,
and the agent to be able to produce both. Today there is no file: orders show on `/app/orders/<id>`,
the supplier gets an email and the supplier console. One cart already splits into one purchase order
per supplier.

## Done when
- From the cart: "הצעת מחיר" makes one document per supplier (products, quantities, price per unit and
  line totals excl. VAT, indicative VAT, the supplier's payment terms and lead time, date, "valid as of").
- From a sent order: the same document titled "הזמנת רכש" with the order number and status.
- Printable / saved as PDF on the phone and desktop, Hebrew RTL.
- Never looks like a חשבונית (CLAUDE.md §5): titled הצעת מחיר / הזמנת רכש, says the supplier issues the invoice.
- With the conversational agent (T-007, draft PR #13): a tool that prepares a quote from the cart or from
  products named in the chat and returns its link.

## Notes
A quote is built from current prices and is not stored as a commitment; the supplier confirms the real
amount on the purchase order. Decide whether a quote is saved (a table) or rendered on the fly.

2026-10-07: the files are built, without the agent. `/doc/quote` renders the cart as one "הצעת מחיר"
per supplier from current prices (not stored), `/doc/order/[id]` renders a sent order as "הזמנת רכש"
with number, status and the supplier's confirmed amount. Both are server-gated to the signed-in
carpentry, open from the cart and the order page, and print one A4 page per supplier via the
browser's print / save as PDF. Verified by rendering sample data on an iPhone 13 viewport (no
horizontal overflow) and to an A4 PDF (2 suppliers, 2 pages). Left: the agent tool, with T-007.
