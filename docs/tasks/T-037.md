## Context
Suppliers now sign in like carpentries (T-032): the `/supplier/join` login box mails a six-digit
code to the address on file, next to the entry link, and the code typed on the same page signs that
browser in (`/api/supplier/login-code`, `lib/login-code.ts` with kind `supplier`). The codes need
table `supplier_login_codes` (migration `20261105180000_supplier_login_codes`). Until it is applied
the code cannot be stored, and the email goes out with the link alone: the page still shows the
code step, so a supplier would have to use the link.

## Done when
- The migration is applied on staging and production, history row `20261105180000` on both.
- On staging: a supplier asks for a code, types it and lands in `/supplier`; a reused code and the
  sixth wrong try are refused.
- `npm run db:types` after production, and the generated types match the hand-added ones.
